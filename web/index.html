Reasoning is disabled by default (reasoning_effort: none). With it on, thinking consumes most of the output budget, so decode tk/s would describe the chain of thought rather than the answer — and stop being comparable between models that think by default and models that do not.

GPU watts are measured — nvidia-smi on Windows/Linux, powermetrics on macOS. Total system watts are estimated: GPU + non-GPU idle + CPU TDP × measured CPU load, except on macOS where the CPU rail is measured directly and the TDP field is ignored. Set the constants from a wall meter if you have one.
